# Advent of Code 2026

My solutions for [Advent of Code 2026](https://adventofcode.com/2026).

Targeted language: [Nim](https://nim-lang.org/). Fallback language: Python.

## Versions

* Nim: 2.4.2
* Python: 3.14.10
* Operating system: Linux
